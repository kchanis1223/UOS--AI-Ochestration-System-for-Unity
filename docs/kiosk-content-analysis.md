- **leaf(억새능선)** 는 시안 없이 콘텐츠 사진만 → 갤러리에서 진입하는 사진 상세.
- 텍스트 콘텐츠는 **`기획서.pptx` slide 8/9/10** 에 품목별 개요·주소·특징으로 존재 (천관산 개요 = 시안 텍스트와 일치 확인).
- 현재 **천관산 가지만 완성**, 9미/9품·대부분 스팟은 미완성.

## 5. UOS 플래너 적합성 & 정교화 포인트

Stage 1 플래너의 (폴더=화면 · menu/detail · 드릴다운+뒤로+홈) 매핑이 이 기획과 일치하며, 크롬의 홈/뒤로 버튼과 정확히 대응됩니다. 다만 충실도를 위해 다음을 보강:

1. **`화면 구성.png` → 레이아웃 레퍼런스**로 인식 (콘텐츠 미디어와 분리). plan에 `layoutReference` 필드.
2. **콘텐츠 미디어(Test_Image_*)** → `contentMedia` 필드 (상세/갤러리 사진).
3. **`기획서.pptx` 품목명 ↔ 개요 텍스트 매칭** → 상세 화면 텍스트 소스.
4. **menu 화면도 시안 기반**(테마 카드/캐러셀/갤러리) — 단순 버튼 목록이 아님.
5. **상세 허브(천관산)**: 자식 보유(menu) + 자체 콘텐츠(개요/히어로) 동시 → "콘텐츠 보유 메뉴"로 처리.

## 6. Stage 2 방향 (제안)

- 각 화면을 **`화면 구성.png` 시안을 레퍼런스로 재현**(`create_image_reference_screen`) 후, 그 위에 인터랙션(카드→드릴다운, 홈/뒤로 전환)과 콘텐츠(개요 텍스트·사진)를 배치.
- **`verify_screen_against_reference`** 로 시안 대비 정합을 검증하는 수정 루프.
- 미완성 폴더(9미/9품 등)는 `기획서.pptx` 텍스트로 골격을 먼저 생성하고, 시안이 들어오면 교체.

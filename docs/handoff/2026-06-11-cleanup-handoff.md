## Latest Implemented Behavior

- Running `uos` with no extra command opens the project catalog before opencode.
- The catalog scans configured Unity project roots from UOS config.
- Projects show UOS connection/install status and live bridge status.
- Keyboard and supported mouse input can select projects.
- `c` installs/updates UOS package wiring for a project.
- `d` disconnects UOS package wiring from a project.
- Entering an uninstalled project now installs UOS automatically before opencode opens.
- The launcher starts opencode with the Ochestrator agent for the selected Unity project.
